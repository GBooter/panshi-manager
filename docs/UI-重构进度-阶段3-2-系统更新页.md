# UI 重构进度 — 阶段 3-2：系统更新页

> 前置：阶段 0/1/2 及 3-1（关于页）均已验收通过。
> 本轮另含一项评审项修复：关于页窄窗口命令折行。

## 一、评审项修复：关于页命令折行（aboutpage.cpp）

- 新增匿名命名空间类 `ElidedCommandLabel`（DLabel 子类，无 Q_OBJECT）：
  - `setWordWrap(false)`，`paintEvent` 用 `QFontMetrics::elidedText(ElideMiddle)` 自绘；
  - 悬停 tooltip 始终为完整命令；行尾复制按钮复制的也是全文（选择文本交互随之取消，与复制按钮功能重叠，无功能损失）；
  - `makeCommandRow` 中命令标签改为 stretch=1 弹性占位，窄窗口时命令中部省略，说明文字与复制按钮始终可见，不再折成 3 行。

## 二、BasePage 小扩展（basepage.h）

- 新增 `void setMaskLoadingEnabled(bool)`（默认 true，未迁移页面行为不变）；
- `runAsync` 中 `showLoading` 受该开关保护；`hideLoading()` 照旧无条件调用（遮罩未显示时无副作用）。
- 这是「加载态三档分级」（方案 §4.6）落在 BasePage 上的最小改动，后续页面迁移时逐页关遮罩。

## 三、系统更新页重写（updatepage.h / updatepage.cpp 全量重写）

| 区域 | 旧 | 新 |
|---|---|---|
| 结果展示 | `m_resultLabel`（#panshiResultBox 结果框）+ errorDialog 模态弹窗 | `PanshiInlineBanner`：成功=Success 自动 3s 消失；失败=Danger 常驻可关闭 |
| 升级完成 | 再弹一个 confirmDialog 问是否重启 | Banner Success 文案 + 行内「立即重启」suggest 按钮 |
| 加载 | 整页遮罩（setLoadingText + runAsync 默认） | L2 `PanshiLocalLoading`（按钮区下方 spinner + 文字），`setMaskLoadingEnabled(false)` |
| 长输出 | 直接铺在结果框 | `PanshiCollapsible("完整输出")`（等宽、可选中），无输出时整块隐藏 |
| 结构 | Ui::card() + panshiRowDesc | `PanshiSection`（更新说明 / 操作） |
| 重复触发 | 无防护 | `m_running` 防重入（三个槽共用） |

- 「立即重启」按钮在构造时创建一次并隐藏，升级成功才 `setVisible(true)`——避免 `addAction` 在重复升级时堆积按钮。
- style.h 顺带删除已无使用者的 `#panshiResultBox` / `#panshiCmd` 规则。
- 升级前的 confirmDialog 保留（这是"确认危险意图"而非"反馈结果"，符合 §4.4 分工）。

## 四、需编译侧验证（5 点）

1. **L2 局部加载**：检查更新 / 升级 / 清缓存期间整页不再出现灰遮罩，spinner 出现在「操作」分组按钮下方，任务完成后消失。
2. **Banner 三态**：检查成功→绿色系（Highlight 柔和底）「检查完成」3 秒自动消失；失败→危险色常驻、右侧有关闭按钮；升级成功→「系统升级完成，需重启后进入新系统」+「立即重启」按钮出现。
3. **完整输出折叠区**：有输出才出现；展开后等宽、可选中复制；新任务开始时收起隐藏。
4. **防重入**：任务进行中再点任一按钮无响应（不排队、不叠加）。
5. **关于页窄窗口**：拖窄窗口，命令行不再折行，命令中部出现省略号，说明与复制按钮保持可见；悬停命令可见完整命令 tooltip。

## 五、已知小事项（不阻塞）

- Banner 的 `autoDismiss` 定时器与「3 秒内再次操作」存在轻微竞态：旧定时器可能把新 Banner 提前隐藏。表现无害（再点一次即恢复），阶段 4 交互收尾时统一处理。
- ElidedCommandLabel 取消了鼠标选中文本（自绘无法支持选择），由 tooltip + 复制按钮覆盖同一需求。
- 深色主题焦点框手测项仍挂起（系统接口切不动，需控中心手动切换后 Tab 进侧栏目测）。
