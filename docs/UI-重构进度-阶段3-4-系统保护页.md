# UI 重构进度 — 阶段 3-4：系统保护页

> 前置：阶段 0/1/2、3-1（关于）、3-2（系统更新）、3-3（策略与设置）均已验收通过。

## 一、改动内容

### protectionpage.h
- 状态区：`QList<QWidget *> m_statCards` + `statCard()` 自绘方案 → 3 个 **`PanshiUi::PanshiStateCard`**（`m_cardProtect` / `m_cardWritable` / `m_cardReboot`）；
- 新增 `PanshiInlineBanner *m_banner`、`PanshiLocalLoading *m_busy`、`bool m_running`；
- 引入 `ui/components.h`。

### protectionpage.cpp 全量重写
| 维度 | 旧 | 新 |
|---|---|---|
| 状态卡 | `Ui::card()` + `panshiStatValue` + `stat` 属性 + QSS 属性选择器染色 | `PanshiStateCard`（数值 + 状态徽章，语义取自 DPalette） |
| 状态区布局 | 固定 3 列 `QGridLayout` | `QHBoxLayout` 三卡等宽自适应（窗口变窄随之压缩） |
| 危险操作 | 与常规操作同层平铺（3 个按钮并排） | 常规「开启保护」平铺；**「永久/临时关闭保护」收进 `PanshiCollapsible`（默认收起）**，折叠区内带警告说明 + 两个危险按钮 |
| 说明/开关 | `Ui::card()` + `cardTitle()` | `PanshiSection`；开关行 `PanshiSwitchRow` 保留在组内 |
| 反馈 | `infoDialog` / `errorDialog` 模态 | `PanshiInlineBanner`：成功 5s 自动消失（重启提示需留出阅读时间），失败常驻可关 |
| 加载 | 整页遮罩 | `PanshiLocalLoading` + `setMaskLoadingEnabled(false)` |
| 防重入 | 无 | `m_running` 守卫 |

**行为保持不变**：`setProtect()` 的命令调用（`disableWritable` / `enableWritable`）与确认流程（关闭类传 `danger=true`）逐行等价；成功后仍回调 `refresh()` 回显真实状态；`PanshiSwitchRow::switchChanged` → `m_win->refreshPanshiPages()` 同步链路不变。

## 二、需编译侧验证（5 点）

1. **状态卡**：三卡等宽排布，数值 + 状态徽章正常；开启可写层时「只读保护」为危险语义色、「可写层」为警告语义色；保护开启时三卡为正常/次要语义色。
2. **危险折叠区**：默认收起（标题「▸ 关闭保护（高级操作）」）；展开后出现警告说明 + 两个危险按钮，点击行为与旧版一致（走确认对话框）。
3. **反馈**：设置成功 → 绿色 Banner「设置成功! 请重启系统使设置生效。」5s 后消失；失败（本机无 sudo 时常见）→ 危险色常驻 + X 可关。
4. **无遮罩**：读取状态与设置保护期间页面内容保持可见可交互，无整页灰遮罩。
5. **防重入**：任务进行中再点按钮无响应。
