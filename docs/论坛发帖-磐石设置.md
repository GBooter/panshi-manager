## 正文

deepin 25 的磐石（只读根）架构很稳，但日常管理基本只有命令行：`deepin-immutable-ctl` 管快照和升级，`deepin-immutable-writable` 管可写层。想看一眼「现在保护开没开」「这个快照占多大」「磁盘怎么突然涨了 20G」，都得敲命令。

所以我用 C++ / Qt6 / DTK6 写了个原生小工具 **「磐石设置」（panshi-manager）**，把这些命令包成图形界面，分享给有同样需要的朋友。

一句话：它是 deepin 25 磐石系统的图形化管理面板，**全程点击，不用记命令**。

【配图 1｜放这里：主界面全貌（总览页）】

### 七个页面

| 页面 | 能做什么 |
|---|---|
| 总览 | 保护状态总开关、可写层状态、快照统计、仓库占用、系统信息；「立即创建备份」「检查更新」可一键跳转并自动执行 |
| 磁盘空间 | 后台持续监控（关掉软件也采样）；时间线看每日占用变化（默认近 7 天，最长一年）；**从「哪天暴涨」下钻到「哪个文件夹/文件」并一键打开**；容量预测与异常告警通知 |
| 系统保护 | 只读保护开关，支持「临时关闭（重启后自动恢复）」和「完全关闭」，危险操作带确认与倒计时 |
| 备份与版本 | 快照的创建/删除/还原；**还原前自动先建一份「回滚前备份」**；可启动系统版本列表与旧版本清理 |
| 系统更新 | 检查更新、原子升级、清理升级缓存 |
| 策略与设置 | 备份数量上限与超限自动清理、升级失败自动回滚、保留旧部署数量、磐石系统参数（需管理员权限，显式保存） |
| 关于 | 版本信息、技术说明、常用命令速查 |

### 几个可能对你有用的点

- **原生 DTK**：按钮/开关/对话框全用 DTK 控件，亮暗主题跟随系统，图标跟随系统图标主题，不是套皮肤。
- **设置搜索**：侧栏顶部输入关键词，直接定位到对应开关并高亮。
- **不弹窗轰炸**：成功操作走页内提示条（自动消失），只有危险操作才弹确认框。
- **回滚保护**：还原系统前强制先建备份，翻车也回得来。
- **监控是用户级 systemd 服务**，无需 root 常驻；需要权限的操作自动走 `sudo -n`，失败回退 `pkexec`。

### 安装

当前版本 **1.0.4**，适用于 deepin 25 磐石版本。

```bash
# 方式一：deb 包（推荐）
sudo apt install ./panshi-manager_1.0.4_amd64.deb

# 方式二：源码编译
sudo apt install -y cmake g++ qt6-base-dev libdtk6core-dev libdtk6gui-dev libdtk6widget-dev
cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j$(nproc)
sudo cmake --install build
```

装完在启动器搜「磐石设置」，或命令行运行 `panshi-manager`。

第一次用建议先做两件事：**在「备份与版本」里手动建一个快照**，再到**「磁盘空间」页打开监控开关**，让它跑几天攒出时间线数据。
