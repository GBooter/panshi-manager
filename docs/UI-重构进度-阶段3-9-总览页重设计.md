## 二、重设计决策

### 2.1 ① 状态 hero：去掉 section 包装，Surface 面板直接承载开关行

- **不改 `PanshiSwitchRow` 内部**：它仍是总览/保护两页共用的唯一开关实现
  （标题「磐石功能」为保护页搜索索引所依赖，见 protectionpage.cpp 的
  `registerSearchTarget(tr("磐石功能"), …)` 与 `highlightPanshiSwitch`，标题不可改）。
- 改动只在包装层：原 `PanshiSection(磐石功能, 总开关：…)` → `PanshiPanel(Surface)`，
  开关行（图标 + 标题 + 状态副标题 + 详情 + 开关）直接入面板。
  顺带消掉「标题出现两次」与「desc 与开关行副标题语义重复」。

### 2.2 ② 卡组去重：快照卡只报个数

- 快照卡值由 `N 个 · 大小` → `N 个`；大小统一由存储分布图例承担。
- **统一取数口径**：图例与分布条一律用 `RepoSizes::snapshotRoot`，删除旧版
  `computeSnapshotSizes()` 的独立汇总 —— 消除「680.47KB / 680.77KB」两处漂移
  （同一事实两处取数不同源，是阶段 3-5 遗留的隐性不一致）。

### 2.3 ③ 存储分布条（设计文档 P0 ③，新）

- 结构：一条横向堆叠占比条 + 2×2 图例（色点 + 名称 + 数值）。
- 分段 = `/ostree ｜ /persistent ｜ 快照`，余量 = 可用空间（轨道底色）。
- 分母 = 仓库合计 + 可用（系统盘总容量），与图例数值同源。
- **颜色 = 图表系列色，不经过 Semantic 语义映射**（与 usagechart 同一范式）：
  - `/ostree` → `DPalette::Highlight`（主题强调蓝）
  - `/persistent` → `DPalette::TextWarning`（警示橙红）
  - `快照` → `DPalette::TextTips`（灰 = 可忽略量级）
  - 轨道/可用 → `DPalette::ItemBackground`
  - 由页面私有 `enum class BarRole` 统一映射，条与图例共用 `barColor()` 保证同色；
    绘制时实时取色，主题切换自动跟随（沿用项目"落色必须可刷新"的纪律）。
- ⚠️ **为什么不用 Semantic**：Semantic 的 Accent/Success 收敛到同一个 Highlight，
  表达不了三段；图表系列色属于"身份编码"，不属于"状态语义"（同 usagechart 先例）。
- 绘制：先画圆角轨道，再以圆角轨道的 `QPainterPath` 裁剪绘制各分段矩形，
  分段与轨道圆角自然吻合，免去逐角圆角计算。
- 窄窗：条是单控件，无横向溢出风险；图例是 2×2 QGridLayout，每格含 ElidedLabel，
  挤压时优雅省略（沿用阶段 3-8 的"纯文本值给 minW=0"纪律）。

### 2.4 ⑤ 快速操作：图标 + 文字（设计文档 P0 ⑤）

三个按钮补主题图标（themedIcon + QStyle 回落），语义：
`立即创建备份=document-save` / `检查系统更新=system-software-update` /
`保护设置=security`。跳转逻辑零改动。

### 2.5 页头刷新按钮（设计文档 P0 页头 `[刷新]`）

右上角 36×36 `DIconButton(view-refresh)`，点击 `refresh()`。与磁盘页
「立即扫描」同语义层级，不新增遮罩（沿用本页 L1/L2 加载策略）。

### 2.6 区块重排

按设计文档 P0 顺序：`① hero → ② 卡组 → ③ 存储分布 → ④ 系统信息 → ⑤ 快速操作`。
旧版顺序是 `开关 → 卡组 → 系统信息 → 存储 → 快速操作`（存储分布应在系统信息之前）。
